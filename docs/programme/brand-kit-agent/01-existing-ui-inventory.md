# Brand system: existing UI inventory (the contract)

Produced 2 October 2026 from the code on `main` before any Brand Kit Agent work. The agent writes into the data
each section already reads; the sections below say what that data is, what each section renders from it, what
its editor does, and what a generated draft must therefore contain to render exactly as a manually built kit.
Where the brief and this inventory conflict, the inventory wins.

References: R = `apps/web/src/app/c/$company/b/$brand/system/route.tsx`, V = `features/brand/brand-read-views.tsx`,
E = `features/brand/brand-kit-editor.tsx`, SI = `brand-skill-import.tsx`, VX = `voice-extraction.tsx`,
C = `packages/contracts/src/brand.ts`, S = `packages/modules/brand/src/service.ts`, G = `guidelines.ts`,

## 0. Shared behaviour

- Document `BrandSystemDocumentV1` (C:24-89): `voice`, `tokens` (colours, typeRoles, spacingScale, radii,
  contrastTarget), `logoRules`, `patterns`, `channelGuidance`, optional `guidelines`. `emptyBrandSystemDocument`
  (C:93-108) is the start of a draft with no published predecessor.
- Version shown (R:159-164): `?version=`, else the published version, else the working version (newest draft or
  in-review above the published number). `editable` = draft or in_review (R:176). An editable version renders the
  `BrandKitEditor` for sections with a `kit`; Overview, Patterns and Channels have no kit and always show the read
  view (R:74-142, 313-372).
- Header (R:224-255): brand name, "Version N · Proposed | In review | Published | Retired" (draft reads
  **Proposed**), the first 12 characters of the content hash, and the published/working toggle. An editable
  version shows the banner "You’re viewing version N, {state}" with "Review changes" (R:257-275).
- Empty state helper: "No {what} in this version." (V:48).
- Asset previews: `AssetById` → `trpc.assets.get` → thumbnail derivative through a signed URL; "Unavailable",
  "Loading", "Processing" or "No preview" otherwise (V:25-46, `asset-thumb.tsx`).
- Contrast: WCAG 2 relative luminance; `#RGB` or `#RRGGBB` only, otherwise null (E:58-75).
- Saving (E:86-180): the editor holds the whole document in local state; "Save brand kit" sends the whole
  document with `expectedVersion`; "Discard changes" resets; the editor remounts after a save. Errors list
  `path issue` items from the server.

## 13. What rejects a generated document (S:212-254, zod)

Non-hex or 8-digit colour values; empty or duplicate colour keys; a logo rule on anything but a non-retired `logo`
asset of the brand; a ground key not in the palette; a pattern example that is not a brand asset; a new or changed
type role on anything but a `font` asset of the brand; more than 200 distinct asset ids in one document;
`voice.summary` over 2000 characters or more than 12 tone words; guidelines outside their limits. Not validated:
counts of colours, rules, patterns or roles; duplicate variants or roles; numeric ranges; `channelGuidance`;
`templateVersionIds`.
