# Decisions (D-27 onwards)

Working defaults applied so implementation can proceed, each with what confirms it. Registered in
`docs/decisions/DECISIONS.md` as "Open (working default applied)" unless marked decided. D-23 to D-26 are the
production-UI programme's rows (`docs/programme/production-ui/04-decision-log.md`).

| ID   | Decision                                 | Working default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Confirmed by                                                                                                                        |
| ---- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| D-27 | Appearance: the supplied interface's palette and type become the base tokens | The mandate asks for the interface's colour palette, typography, spacing and components; D-12's working default ("no global token overwrite; colour comes from the pack") gave the neutral placeholders and the Ore & Tar pack. Resolution: the neutral placeholders in `packages/ui/src/tokens.css` are replaced by the interface's palette (light and dark), Lato is the application face (requested at start-up, never awaited), and the type scale, radii, shadows and motion follow the interface. The deployment-pack mechanism (D-12) is unchanged: a pack still overrides these tokens at deploy time, so a deployment configured with the Ore & Tar pack keeps that pack's colours over the interface's. Whether this deployment keeps the Ore & Tar pack active or runs the interface as supplied is the owner's: the pack is one variable (`OREMEDIA_DEPLOYMENT_BRAND`), not a code change. Text colours were re-derived so every text pair meets 4.5:1 on the interface's surfaces (the interface's lighter status values drive dots and bars only). | Owner's choice of pack per deployment; visual acceptance of the rebuilt screens                                                     |
| D-28 | Navigation: screens the interface has no entry for | The interface's navigation is Home, Review, Calendar, Campaigns, Studio, Performance, Reports, Intelligence, Experiments, Agents, then Brand system, Assets, Settings. The application also has Overview (web sources, search console, the site audit) and Inbox (replying to comments). Inbox stays in the navigation after Performance: it is a daily workflow with its own count and hiding it two clicks deep would make it less discoverable, against the mandate. Overview leaves the navigation and is reached from Performance ("Web, search and audit →") and keeps its route, so bookmarks and the narrow bar still name it. The sidebar sits beside the screen from 900 px (the interface's `narrow` threshold; was 1024 px) and the drawer button keeps its accessible name "Menu" with the interface's three-line glyph. Sign out and the theme toggle move into the account menu at the foot of the navigation (the interface shows the person's name and role there and nothing else). | Owner acceptance of the navigation; the responsive and journey e2e suites                                                           |
| D-29 | Reports: a new screen and module      | The interface's Reports screen (recent reports, a builder with brand, month, comparison month, sections, an executive summary with an assistant, prepared-for/by, brand kit and theme, a multi-page preview, Download PDF, Send to client, Save draft) has no counterpart. It is built as `packages/modules/reports` with its own tables (a new migration), reads from the measurement module (D-14/D-15 rules apply: nothing summed across platforms that is a unique count), the executive summary drafted through the model gateway and always editable, PDF through the existing render path, and "Send to client" only through a delivery the deployment actually has (otherwise the control says what is missing, never a silent success). | Owner acceptance of the report content; the measurement dictionary                                                                  |
| D-30 | Home "+ New document" opens the studio's creation screen | The interface's home shows an inline title form ("Create and open"). The application creates documents from the Studio's creation screen (format, size and template chosen first, STU-1a), so the home's "+ New document" opens that screen rather than a title-only form that would create a document without a format. | Studio PR; owner acceptance                                                                                                         |
| D-31 | Breakpoints                             | The interface's thresholds: the shell's navigation becomes a drawer below 900 px; two-column screens stack below 760 px (Tailwind `md`, 768 px, is used as the nearest existing step). Phone captures are at 390 px, tablet at 768 px, desktop at 1440 px. | Responsive e2e at 390, 768, 1024 and 1440                                                                                           |
