## How the asynchronous pipeline works

A tRPC mutation runs inside `idempotent()` and writes an outbox row. The dispatch loop
(`apps/worker-core/src/dispatch-loop.ts`, 1 s poll) reads it, finds the route registered by `registerOutboxRoute`
in `packages/modules/*/src/outbox-routes.ts` and calls `TemporalWorkflowStarter` (`apps/worker-core/src/temporal.ts`;
`USE_EXISTING` / `ALLOW_DUPLICATE_FAILED_ONLY`). The web reads results back by TanStack `refetchInterval` polling or
`invalidateQueries(pathFilter)`. There is no SSE or websocket channel.
