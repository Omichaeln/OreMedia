# Implementation ledger

Status vocabulary follows the progress ledger: **complete** (verified in the stated mode), **in_progress**,
**open**, **blocked** (reason stated). Verification modes: SR source-reviewed · FU fixture/unit · LW local
db/workflow · SB staging browser · RP real provider · PO production observation. Severity is the brief's baseline
priority. "Work" lists what changes per layer; "Evidence" links land as PRs merge.
